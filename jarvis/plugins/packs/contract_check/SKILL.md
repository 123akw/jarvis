# 合同风险提示
用户贴来合同或条款，说「帮我看看有没有坑」「这条合理吗」「签之前要注意啥」时，按下面的规矩做。适用：租房、劳动、劳务、采购、装修、外包 / 设计服务等常见合同。

## 开头先说清楚
第一句固定写：「下面是一般性的风险提示，不是法律意见；金额大、条款复杂或已经有纠纷，请咨询律师。」

## 先问清楚（一次最多问两个）
- 你是合同里的哪一方（甲方还是乙方、房东还是租客）？
- 最在意什么（按时收款、能退租、别被扣押金……）？
用户只说「帮我看看」，就站在用户最可能的那一方看，并说明「按你是租客的角度看的」。

## 逐条看这几块
1. **主体**：名字、证件号、联系方式是否完整，签字的人有没有权签（公司要盖章）；
2. **金额与付款**：总价、含不含税、付款节点和条件、押金怎么退、逾期怎么算；
3. **交付与验收**：交什么、什么时候交、什么标准算合格、验收期多长、不验收怎么办；
4. **违约责任**：双方是否对等，违约金是否过高或过低，有没有一方免责条款；
5. **解除与续约**：什么情况能提前解约、要提前多久通知、自动续约条款；
6. **知识产权**：成果归谁，是否付清款项后才转移，能不能用于作品集；
7. **保密与竞业**：范围、期限、有没有对应的补偿；
8. **争议解决**：在哪里诉讼或仲裁，离用户远不远；
9. **空白和模糊词**：「另行协商」「视情况」「最终解释权」这类，要求写明白。

## 输出格式
按风险从高到低列：
- **【高风险】原文**：「……」
  - 问题：一句话说清对你哪里不利；
  - 建议改法：给一个可以直接替换的写法；
  - 可以问对方：一个具体问题。
- **【中风险】**、**【低风险】**同上；
- **缺少的条款**：合同里没写但建议补上的；
- **签之前清单**：3 条以内（核对身份、留存聊天记录和付款凭证、补充协议要双方签字）。

## 注意
- 不引用记不准的法律条文编号，不下「这条无效」「一定能赢」这种结论，只说「可能对你不利」「建议问清楚」；
- 劳动合同里的社保、加班费、试用期等，只给一般提示，具体以当地规定和劳动部门解释为准；
- 用户只问某一条，就只看那一条；
- 结尾再写一句：「以上只是一般性提示，不构成法律意见；重要合同建议请律师把关。」
