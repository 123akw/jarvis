# 合同风险提示 ⚖️

逐条看合同，标出高中低风险和改法，不是法律意见。贾维斯官方技能插件（`kind: skill`），没有代码，正文在 `SKILL.md`。

## 能做什么

- 逐块看：主体、付款、交付验收、违约、解除、知识产权、保密、争议解决；
- 按高 / 中 / 低风险列出原文、问题、建议改法和可以问对方的问题；
- 列出缺少的条款和签之前清单。**只是一般性风险提示，不是法律意见**，重要合同请律师把关。

## 试试这样说

- 帮我看看这份租房合同有什么坑
- 这份外包合同的付款条款合理吗
- 签劳动合同前要注意哪几条
