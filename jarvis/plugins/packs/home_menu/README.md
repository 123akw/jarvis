# 家常菜谱 🍲

一周菜单配采购清单，按人数和预算来，照顾忌口。贾维斯官方技能插件（`kind: skill`），没有代码，正文在 `SKILL.md`。

## 能做什么

- 按人数、顿数和忌口排一周菜单，工作日快手、周末可以费点工夫；
- 采购清单按菜场分区列，带大概用量，可以直接截图去买；
- 单道菜给用料、步骤和小窍门；特殊饮食建议问医生或营养师。
