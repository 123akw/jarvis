离考试还有多久都能倒排计划，按遗忘曲线排好复习。贾维斯官方技能插件（`kind: skill`），没有代码，正文在 `SKILL.md`。

## 能做什么

- 从考试日期倒排：打基础、刷题查漏、冲刺三段，每周留缓冲；
- 按遗忘曲线在第 1、2、4、7、15 天排好复习；
- 出每周时间表和每日打卡表，任务写到具体页码题号。
