# 商品上新文案
用户要上架新品、写商品标题、卖点、详情页，或者整理规格参数时，按下面的规矩做。

## 先问清楚（缺什么问什么，一次最多问两个）
- 卖的是什么：品类、材质 / 成分、规格、价格，有没有照片或参数表可以直接贴；
- 卖给谁、在哪卖：自家小程序、网店还是朋友圈；平台有没有字数要求。
用户说「你看着写」就按手头信息直接写，缺的地方标【待补充】。

## 怎么做
1. **先理清事实**：把用户给的信息整理成参数表，没给的项空着标【待补充】，绝不自己补数字。
2. **找卖点**：从「谁用、在什么场景、解决什么麻烦」出发，每条卖点 = 具体特点 + 带来的好处，例如「加厚 300g 面料 → 秋冬单穿也不透风」。
3. **写标题**：品类词 + 核心卖点 + 适用人群 / 场景，30 字以内，给 3 个备选；不堆砌重复关键词。
4. **排详情页**：按买家心里的顺序——一眼看懂是什么 → 为什么值得买 → 细节和用法 → 规格参数 → 售后和注意事项。
5. **顺手给一句上新预告**，方便发朋友圈或社群。

## 输出格式
```
【商品标题】3 个备选
【五条卖点】每条一行：短标题 + 一句话说明
【详情页文案】按 4–5 屏分段，每屏一个小标题 + 2–3 句 + 配图建议
【规格参数表】| 项目 | 内容 |（不知道的写【待补充】）
【售后与提醒】退换规则、保存 / 使用注意（照用户给的写）
【上新一句话】
```

## 注意事项
- 不编造检测报告、认证、专利、产地、功效和销量；用户没给就不写，或写【待补充：请提供检测报告】。
- 不用广告极限词：最好、第一、顶级、全网最低、100%、绝对、国家级 等；不拉踩别家商品。
- 食品、保健品、化妆品、儿童用品不写治疗、减肥、美白、防病之类功效；涉及医疗器械、保健食品的宣传有专门规定，提醒用户上架前对照平台规则或咨询专业人士。
- 价格、优惠、赠品照用户给的写，写清有效期和条件。
- 用户要改时，只改他点名的部分（比如只换标题），其他不动。
