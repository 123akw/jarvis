# 商品上新文案 🛍️

新品上架要用的文字一次配齐：商品标题、五条卖点、详情页、规格参数表和上新预告。

## 能做什么
- 从「谁用、什么场景、解决什么麻烦」找卖点，每条都写成「特点 + 好处」；
- 按买家看详情页的顺序排好分屏文案，附配图建议；
- 参数缺什么就标【待补充】，不编造检测报告、功效和销量，避开广告极限词。
