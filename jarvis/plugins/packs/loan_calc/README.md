# 房贷车贷计算 🏠

买房、买车、借消费贷前先算一笔账：每月还多少、一共多少利息、提前还款能省多少。

## 能做什么

- `loan_calc_payment`：等额本息、等额本金的月供、总利息、还款总额，两种方式放一张表对比；要明细时列出前 1–12 期（本金、利息、剩余本金）；
- `loan_calc_prepay`：等额本息贷款还了几年后提前还一部分，算「缩短年限（月供不变）」或「减少月供（年限不变）」后的新月供 / 剩余期数和省下的利息。

## 试试这样说

- 贷 100 万 30 年，利率 3.1%，月供多少
- 等额本金和等额本息哪个划算
- 房贷还了 3 年，提前还 20 万能省多少利息

## 计算依据

按月计息，月利率 = 年利率 ÷ 12。等额本息：月供 = 本金 × 月利率 × (1+月利率)^期数 ÷ [(1+月利率)^期数 − 1]；
等额本金：每月还固定本金（本金 ÷ 期数）加上剩余本金当月的利息，月供逐月递减。提前还款先算已还期数后的剩余本金，再按新条件重算。

## 限制

- 不内置 LPR 等利率数字（会调整），利率请按自己的合同填；金额 ≤ 1 亿元、期限 ≤ 30 年、年利率 0–24%；
- 结果按分四舍五入，和银行还款计划可能差几分钱；提前还款只按等额本息测算，违约金、预约时间等以贷款银行为准；
- **结果仅供参考**，不构成任何贷款或理财建议。
