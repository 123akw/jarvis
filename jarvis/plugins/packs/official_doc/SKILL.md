# 通知公文
用户要写通知、放假通知、请示、工作报告、函、邀请函这类正式文书时，按下面的规矩做。

## 先问清楚（缺什么问什么，一次最多问两个）
- 发给谁、以谁的名义发：主送单位 / 部门，落款单位；
- 要素：什么事、时间、地点、参加人、要对方做什么、截止时间。
用户说「你看着写」就按下面的结构直接写，没给的要素用【待补充】占位。

## 先分清文种
- **通知**：让下面的人知道或照办（放假、开会、工作安排）；
- **请示**：向上级要批准，一文一事，结尾「妥否，请批示」；
- **报告**：向上级汇报情况，不夹带请求批准的事；
- **函**：平级或不相隶属的单位之间商洽、询问、答复；
- **邀请函**：请人来参加活动，写清时间地点、日程、回执方式。
用户说的文种不合适时，提一句建议（比如「要领导批准用请示更合适」），按用户最后定的写。

## 结构
```
标题：（发文单位）关于××××的通知 / 请示 / 函
主送：××部门 / 各位同事：
正文：
  开头——为什么发（依据或缘由，一两句）
  主体——具体事项，分条写：一、二、三……
  结尾——要求或惯用语（特此通知 / 妥否，请批示 / 请予函复）
附件：（有就写名称）
落款：发文单位
日期：××××年×月×日
```

## 写法
1. 一件事一份文，分条写，每条一句话说清「谁、什么时候、做什么」。
2. 措辞正式、简洁，不用口语、网络用语和表情；但也别堆「高度重视、切实加强」这类空话。
3. 放假通知写清：放假起止日期、调休上班日期、值班安排、安全提醒；日期和星期要对得上，拿不准就标【请核对日期】。
4. 时间写全：年月日 + 星期 + 几点；地点写到房间号。

## 注意事项
- 不编造文件依据、文号、政策条款和领导姓名；用户没给的写【待补充】。
- 正式的党政机关公文有国家标准规定的格式（字体、版式、文号等），各单位也有自己的要求，提醒用户以本单位格式要求为准。
- 涉及处分、合同、劳动关系等法律事项的文书，只给一般写法，建议用户请法务或专业人士把关。
- 用户要改时，只改他指出的那一处。
