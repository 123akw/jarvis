# 快递查询 📦

把快递100 官方的远程 MCP 服务接进贾维斯：输快递单号查物流到哪了，寄件前估运费、估几天能到。开网店、做微商、天天收发快递的人用得上。

## 它是谁家的服务

- 服务方：快递100（API 开放平台 <https://api.kuaidi100.com>），官方 MCP 开源仓库 <https://github.com/kuaidi100-api/kuaidi100-MCP>（Apache-2.0）。
- 地址：`https://api.kuaidi100.com/mcp/streamable?key=${KUAIDI100_KEY}`（官方 README 推荐的 Streamable 方式；另有 `/mcp/sse` 老式地址）。
- **需要 Key**：管理员在「插件管理 → 快递查询 → 配置」里填 `KUAIDI100_KEY`。去快递100 API 开放平台注册，登录后在账号信息里能看到授权 key。官方 README 写明新账号可以**免费试用 100 单**，之后按快递100 的价格收费——用之前先看清楚。Key 加密存储、不回显；没填之前插件显示「需要配置」。

## 能做什么

2026-10-02 本机实测：`api.kuaidi100.com/mcp/streamable` 可达；不带有效 Key 时返回「用户鉴权失败」，所以**没有用真 Key 跑 `tools/list`**。下面的工具名取自官方开源仓库 `api_mcp.py`（已核对），远程服务以管理员填好 Key 后贾维斯拉到的工具清单为准。

| MCP 工具名 | 做什么 |
| --- | --- |
| `query_trace` | 按快递单号查实时物流轨迹（顺丰、中通等要填寄 / 收件人手机号） |
| `auto_number` | 按单号猜是哪家快递公司 |
| `estimate_time` | 寄件前预估几天能到 |
| `estimate_time_with_logistic` | 已经在路上的件，按轨迹预估到达时间 |
| `estimate_price` | 按快递公司、收寄地址和重量估运费 |

在贾维斯里的名字是 `kuaidi100__<工具名>`，例如 `kuaidi100__query_trace`。

试试这样说：「帮我查一下这个快递单号到哪了」「寄 2 公斤的包裹到外省大概多少钱」。

## 数据会发给谁

快递单号、收寄地址，以及顺丰 / 中通等查件时要的手机号，会连同管理员的 Key 发到快递100 的服务器（境内）。手机号属于个人信息，只在查件需要时提供。返回的内容贾维斯只当「外部资料」参考，不当指令执行。
