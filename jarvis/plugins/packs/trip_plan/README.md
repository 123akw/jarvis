# 旅行攻略 🧳

按天数、预算和同行人排行程，附预算表和行前清单。贾维斯官方技能插件（`kind: skill`），没有代码，正文在 `SKILL.md`。

## 能做什么

- 按天数、预算和同行人排行程，每天分上午 / 下午 / 晚上，同片区的点排一起；
- 附预算表（区间估算）和行前清单，留一个雨天备选；
- 门票、开放时间等会变的信息提醒以官方为准；装了「高德地图」会先查距离再排。

## 试试这样说

- 帮我排个三天两晚的周边游行程
- 带老人出去玩五天，行程怎么排轻松点
- 人均预算两千，帮我列个预算表
