# 日期工作日 📆

算工作日、往后数几个工作日，自动扣掉法定节假日、算上调休上班日。纯 Python 标准库，不联网、不读文件。

**能算什么**
- `workday_calc_count`：两个日期之间相隔几天、有几个工作日（含首尾），中间有哪些假期和调休上班日。
- `workday_calc_add`：从某天起往后 / 往前数 N 个工作日（或自然日）是哪天、星期几（不含起算当天）。
- `workday_calc_holidays`：列出某一年的放假和调休安排，附通知文号和原文链接。

**试试这样说**：「今天到月底还有几个工作日」「从下周一起往后数 10 个工作日是哪天」「今年国庆怎么放假，哪天调休上班」

**数据来源**（中国政府网原文，2026 年 10 月核实）
- 2025 年：《国务院办公厅关于2025年部分节假日安排的通知》国办发明电〔2024〕12 号，2024-11-12 发布，[原文](https://www.gov.cn/zhengce/content/202411/content_6986382.htm)
- 2026 年：《国务院办公厅关于2026年部分节假日安排的通知》国办发明电〔2025〕7 号，2025-11-04 发布，[原文](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)

**限制**
- 只收录了 2025、2026 年。其他年份只按周末算，结果里会提醒「放假安排还没公布 / 没有收录」。2027 年的通知一般在 2026 年 11 月前后发布，出来后在 `tools.py` 的 `HOLIDAY_DATA` 里照格式加一年即可。
- 只算全国统一的法定节假日；地方性假日（如少数民族节日）、单位自己的放假安排、部分人群放假（妇女节、青年节等）不算在内。
- 日期请先换算成 `YYYY-MM-DD`；一次最多算 10 年左右。
