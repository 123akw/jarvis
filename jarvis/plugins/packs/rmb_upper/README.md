# 金额大写 💴

把阿拉伯数字金额转成人民币大写，报销单、收据、合同、支票上直接照抄，不用再一个字一个字对。

## 能做什么

- `rmb_upper`：数字金额 → 大写（壹贰叁…元角分整），同时给出 ¥1,680.32 这样的小写写法；
- 认得「12,345.67」「¥3,000」「1.2万」「3亿」这些写法；超过两位小数的按四舍五入保留到分，并提醒你。

## 试试这样说

- 1680.32 的大写怎么写
- 帮我把 12 万 5 千元写成大写
- 报销单上 3,050 元大写是多少

## 写法依据

中国人民银行《正确填写票据和结算凭证的基本规定》：到「元」或「角」为止的写「整」，有「分」的不写「整」；
数字中间连续有几个 0 只写一个「零」；元位是 0 而角、分不是 0 时「元」后写「零」（¥1,680.32 → 壹仟陆佰捌拾元零叁角贰分）；
万位是 0 而仟位不是 0 时不写「零」（¥107,000.53 → 壹拾万柒仟元零伍角叁分）；「壹拾」的「壹」不省。

## 限制

- 只支持 0 到 1 万亿（不含）的金额；负数没有大写写法，会提示你按正数写再注明退款或红字；
- 各单位的财务制度可能有自己的细则（例如是否必须写「整」），以单位规定为准。
