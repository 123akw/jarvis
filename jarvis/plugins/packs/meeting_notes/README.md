# 会议纪要整理 🗒️

会议录音转写出来的一大段文字、开会时随手记的笔记，贴进来就整理成一页纸的纪要。

## 能做什么
- 去掉口头禅和闲聊，按议题理出讨论要点和最终决定；
- 待办单独成表：谁、做什么、什么时候前，没说清的标「待确认」，不替你编；
- 吵了没定的事放进「待定事项」，转写可能听错的数字和名字提醒你核对。

## 试试这样说
- 把这段会议录音的文字整理成纪要
- 这是我开会随手记的，帮我理一下
- 从纪要里把待办事项单独列出来
