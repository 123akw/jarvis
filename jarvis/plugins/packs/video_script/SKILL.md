# 短视频口播稿
用户要拍短视频、写口播稿、做带货或知识分享脚本，或者嫌自己的稿子太平时，按下面的规矩做。

## 先问清楚（缺什么问什么，一次最多问两个）
- 讲什么、想让看的人做什么：买东西、到店、关注，还是记住一个知识点；
- 多长：默认 30 秒（约 120 字），用户说「一分钟」就按 60 秒（约 240 字）；
- 谁出镜：老板本人、店员，还是只有画面加配音。
用户说「你看着写」就按 30 秒、本人出镜、真诚分享的口吻直接写。

## 怎么写
1. **前 3 秒钩子**：一句话把人留住。可以用痛点（「衣服一洗就起球？」）、反常识（「冰箱放水果其实很伤」）、结果先行（「这张桌子只花了两百」）。不说「大家好，今天给大家介绍」。
2. **中间讲清一件事**：只讲 1 个核心卖点或 1 个方法，配 2–3 个具体细节（怎么用、用在哪、和普通做法比好在哪）；口语短句，一句不超过 15 个字，方便念。
3. **结尾一个动作**：评论区留言、看主页、到店说暗号，只给一个，别一口气说三个。
4. 按秒数控字数：大约每秒 4 个字，超了就删，宁短勿长。

## 输出格式
```
【标题】视频封面上的字（12 字以内，给 2 个备选）
【口播稿】按段落写，每段前标时间：0–3 秒 / 3–20 秒 / 20–30 秒
【分镜】镜头 1：拍什么、怎么拍（近景 / 手部特写 / 对比画面）……
【字幕重点】需要放大加粗的 3–5 个词
【拍摄提醒】光线、背景、道具，一两句
```

## 注意事项
- 不编造销量、好评、检测结果和「专家说」；用户没给的数据写【待补充】。
- 不用广告极限词：最好、第一、顶级、全网最低、100%、绝对 等；食品、保健、化妆品不说治疗、减肥、美白之类功效。
- 涉及健康、理财、法律的内容只讲一般常识，结尾提醒「具体情况请咨询专业人士」。
- 不教搬运、洗稿别人的视频，不蹭与内容无关的热点。
- 用户要改时，只改他点到的那一段（比如只改开头），其他保持不动。
