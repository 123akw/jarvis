# 店铺活动方案
用户说「店里想搞个活动」「周年庆 / 节日怎么促销」「满减和打折哪个划算」时，按下面的规矩做。

## 先问清楚（缺什么问什么，一次最多问两个）
- 活动想达到什么：清库存、拉新客、带老客回来，还是冲营业额；
- 账的底子：主推商品的售价和进货成本、大概预算、活动几天。
用户说「你看着写」就先给方案框架，算账部分列公式和要填的数，不替他假设成本。

## 怎么做
1. **定目标**：一句话写清，最好带个能数的数，例如「3 天卖掉 200 件库存」「新加 50 个会员」。
2. **选玩法（给 2 个对比）**：清库存用第二件半价、组合价；拉新用新人价、拼单、老带新；促复购用会员日、储值送、集点卡。说清每种适合什么、风险在哪。
3. **算账**（核心，不能省）：
   - 单件毛利 = 售价 − 成本；活动后单件毛利 = 活动实收价 − 成本；
   - 满 200 减 30 相当于最多让利 15%；第二件半价两件平均 75 折；
   - 保本要多卖 = 活动总投入（物料 + 让利 + 赠品）÷ 活动后单件毛利；
   - 活动后毛利为负的商品不进活动，或者设限量。用户给了数就代进去算出结果，没给就只列公式。
4. **物料和渠道**：海报、价签、朋友圈 / 社群文案、店门口立牌，列清单，标谁来做。
5. **执行时间表**：预热（前 3 天）→ 活动期 → 收尾（后 1 天），每天做什么。
6. **复盘指标**：营业额、客单价、新增会员、活动品毛利，活动前先记下平时的数，好对比。

## 输出格式
```
【活动目标】
【玩法对比】方案 A / 方案 B：怎么玩 · 适合 · 风险
【算账】按上面公式，写出每一步
【活动规则】时间、门槛、限量、能否叠加（不写「最终解释权归本店所有」）
【物料清单】
【执行时间表】
【复盘看什么】
```

## 注意事项
- 不编成本、销量、往年数据；没给的写【待补充】。
- 活动规则写清楚门槛、时间、限量和能否叠加，避免「最低价」「全网第一」这类极限词，先涨后降的「假打折」不要做。
- 涉及储值卡、会员费、抽奖的，提醒用户留意当地对预付卡和有奖销售的规定，拿不准就咨询专业人士。
- 用户要改时，只调整他说的那一项（比如只换玩法），其他保持不变。
