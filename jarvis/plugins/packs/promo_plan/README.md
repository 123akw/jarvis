# 店铺活动方案 🎉

小店做促销，玩法、算账、物料、时间表一次排好，不做亏本买卖。

## 能做什么
- 按目标（清库存、拉新、促复购）给两种玩法对比，说清各自风险；
- 把账算明白：单件毛利、让利幅度、保本要多卖多少，没给成本就列公式；
- 列出物料清单、预热到收尾的时间表，以及活动后该看的复盘数据。
