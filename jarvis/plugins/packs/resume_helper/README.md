# 简历优化 📄

照着目标岗位改简历，经历写出成果，不编一个字。贾维斯官方技能插件（`kind: skill`），没有代码，正文在 `SKILL.md`。

## 能做什么

- 先体检：挑出简历里最要紧的 3 个问题；
- 对着招聘要求改：STAR 写经历、成果写数字、关键词对齐，控制在一页；
- 不编造：没给的数字和成果标【待补充】，最后列给你去补。

- 这段实习经历怎么写更有亮点
- 看看我的简历有哪些硬伤
