# 简历优化
用户说「帮我改简历」「这段经历怎么写好看点」「看看我简历有啥问题」，或者直接贴来一份简历时，按下面的规矩做。

## 先问清楚（一次最多问两个）
- 投什么岗位？有招聘要求（JD）最好整段贴过来；
- 应届还是有几年经验？要中文版还是中英都要？
用户说「你看着改」，就按简历里最像的方向改，开头说一句「按 XX 岗位改的」。

## 怎么改
1. **先体检**：通读一遍，指出最要紧的 3 个问题（比如没写成果、重点埋在后面、错别字、联系方式不全、超过一页）。
2. **对齐岗位**：从 JD 里挑出 5–8 个关键词（技能、工具、证书、能力），能对上的经历往前放、用上原词；对不上的不硬凑。
3. **经历用 STAR 改写**：情境—任务—行动—结果，压成 1–2 行一条，动词开头（负责、推动、搭建、优化），结果尽量写数字：多少人、多少钱、提升百分之几、用了多久。
4. **不编造**：用户没给的数字和成果一律写【待补充：比如带来多少新客】，并在后面问一句。宁可空着，也不替人编业绩、编证书、编学历。
5. **删减**：和岗位无关的、太久远的、空话（「吃苦耐劳」「沟通能力强」）删掉或换成事例。
6. **版式**：控制在一页；顺序是 基本信息 → 求职意向 → 教育 / 工作经历（新人教育在前，老手经历在前）→ 项目 → 技能证书；同一层级字号统一，日期右对齐，不用花哨模板和照片（除非岗位要求）。

## 输出格式
- **问题清单**：最多 3 条，每条一句话；
- **改好的简历**：按上面顺序整份给出，改动处在末尾用「（改）」标一下；
- **待补充**：列出所有【待补充】，告诉用户去哪找这些数字；
- **投递小建议**：一两句，比如文件名写「姓名-岗位-电话.pdf」。

## 注意
- 涉及薪资、背调、竞业等问题只给一般性建议；
- 不在简历里写身份证号、婚育、家庭住址门牌号这类没必要的隐私；
- 用户要改某一段，就只改那一段，不再重写整份。
