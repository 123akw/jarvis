# BMI与热量 🥗

按中国成人标准算 BMI、看腰围，再估一估每天大概消耗多少热量，减重、控饮食时心里有个数。

## 能做什么

- `health_calc_bmi`：BMI 和分档（体重过低 / 正常 / 超重 / 肥胖），这个身高的正常体重区间；给了腰围再判断是不是中心型肥胖；
- `health_calc_energy`：基础代谢、按活动量（久坐 / 轻度 / 中度 / 高强度 / 极高）估每日总消耗，附减重和保持体重的一般参考。

## 试试这样说

- 身高 170 体重 75 公斤，算一下 BMI
- 腰围 88 厘米算不算肥胖
- 想减重的话每天吃多少热量合适

## 计算依据

- BMI 与腰围：国家卫生行业标准 WS/T 428—2013《成人体重判定》——BMI < 18.5 体重过低、18.5–23.9 正常、24.0–27.9 超重、≥ 28 肥胖；
  腰围男 85–89.9 cm、女 80–84.9 cm 为中心型肥胖前期，男 ≥ 90 cm、女 ≥ 85 cm 为中心型肥胖；
- 热量：Mifflin-St Jeor 基础代谢公式，乘以常用活动系数 1.2 / 1.375 / 1.55 / 1.725 / 1.9。

## 限制

- 只适用于 18 岁以上成人，**不适用孕妇、哺乳期和职业运动员**；BMI 不区分肌肉和脂肪；
- 热量是估算，个人差异可能有 10% 上下；减重建议只是一般性参考，不会建议吃得比基础代谢还少；
- **结果仅供参考，不是诊断**。身体不舒服、有慢性病或想系统减重，请问医生或注册营养师。
