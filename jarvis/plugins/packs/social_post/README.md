# 朋友圈小红书文案 📣

上新、促销、探店、节日问候，朋友圈、小红书笔记、社群群发的文案一次写好。是示例插件「朋友圈文案教练」（`examples/plugins/moments_coach`）的官方升级版。

## 能做什么
- 朋友圈一次给三版：实在型、故事型、互动型，附发布时机和配图建议；
- 小红书笔记：两个标题备选、分段正文、相关话题标签；
- 改你自己写的文案：指出问题、去掉「最好」「第一」这类广告极限词，不编造优惠和销量。

## 试试这样说
- 帮我写条朋友圈，店里今天上了新品
- 写一篇小红书笔记分享这个好物
- 这段促销文案帮我改改
