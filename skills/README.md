# 技能目录：放一个文件，贾维斯就长一个新本事

在这个目录下建一个子目录、放一个 `SKILL.md`，**下一轮对话立即生效**，不用改代码、不用重启服务：

```
skills/
└── lobster/
    └── SKILL.md
```

`SKILL.md` 的格式：

```markdown
# 技能名称
正文就是给贾维斯的扩展指令，用大白话写清楚
什么时候用、按什么规矩做即可。
```

规则：

- 首行 `# 名称` 是技能名（缺了就用目录名）；正文为空的技能会被跳过。
- 改文件、删文件同样即刻生效（每轮对话现读现用）。
- 护栏：最多加载 20 个技能（按目录名排序先到先得），单技能正文超过 2000 字符会被截断。
- 读不了的文件安静跳过，永远不会因为技能文件坏了拖垮对话。
- 私有部署可用环境变量 `JARVIS_SKILLS_DIR` 把技能目录挪到仓库外。

技能是提示词级扩展（改变行为与说话方式），不能新增工具调用能力；需要新工具仍要走 `jarvis/tools/`。
