# JWS-Agent 宣传型 README 改版设计

日期：2026-08-11  
状态：待用户书面复核

## 目标

把现有 README 从以安装说明为主的技术文档，升级为兼顾项目宣传、产品展示和完整上手的中文项目主页。读者在首屏应能理解 JWS-Agent 是什么、有哪些入口、能解决什么问题，并能继续向下完成安装、配置和验收。

本次只修改文档和文档图片，不改变网页、桌面悬浮窗、微信桥、Agent、工具或部署配置。

## 受众与表达定位

- 主要受众：第一次访问仓库的开发者、AI Agent 爱好者和希望搭建个人助手的个人用户。
- 语气：有产品感但不过度营销；突出“私人管家、持续记忆、多入口、可追溯实时搜索”。
- 所有能力描述必须与当前代码一致。尚未配置密钥的联网能力写成“配置后可用”，不得写成生产已启用。
- README 使用简体中文，命令、变量和工具名保留原文。

## README 信息架构

1. **首屏 Hero**
   - 项目名、简洁宣传语、技术徽章。
   - 一段 2–3 句价值说明。
   - 当前网页地址、快速开始锚点和非商用声明。
2. **产品预览**
   - 网页端全景主图。
   - 悬浮球、展开式快捷对话窗、设置/微信入口三张辅助图。
   - 每张图配一句可验证的功能说明。
3. **为什么使用 JWS-Agent**
   - SQLite 持久记忆。
   - 网页、桌面、终端、个人微信四入口。
   - 20 项工具与可追溯实时搜索。
   - 私有部署与安全边界。
4. **典型场景与对话示例**
   - 晨报、日程/待办、记忆续接。
   - 娱乐新闻、电影评分、电竞比分、票务信息。
   - 示例明确区分真实实时结果与示意文本，不伪造当前价格或比分。
5. **功能矩阵与架构**
   - 用表格对照四个入口。
   - 用 Mermaid 展示入口、FastAPI/LangGraph、工具层、存储和外部数据源。
6. **安装与运行**
   - 环境要求、虚拟环境、依赖安装、`.env`、网页/终端/桌面启动。
   - Tavily 必需于实时搜索；PandaScore 可选。
7. **微信桥、验收、常见问题与安全说明**
   - 说明专用小号建议和第三方个人号风险。
   - 保留完整测试与 smoke 命令。
8. **作者与使用许可**
   - 明确写出“本项目由陈文杰、钟俊琅共同开发”。
   - 明确限定为学习、研究和个人非商业用途，禁止任何形式的商业使用。

## 截图与素材方案

素材目录固定为 `docs/assets/readme/`，文件名使用英文小写和连字符：

- `web-dashboard.png`：网页端主界面全景，桌面宽屏比例。
- `desktop-orb.png`：MOSS 红瞳悬浮球。
- `desktop-chat.png`：展开后的快捷对话面板。
- `desktop-settings.png`：设置页与微信桥入口，不展示二维码。

截图必须来自当前代码运行出的真实界面，不使用 AI 生成图或重绘效果图。网页端使用隔离的临时数据目录和演示会话；桌面端连接同一演示服务。允许裁切窗口边缘和统一尺寸，不允许修改界面内容来制造不存在的能力。

### 隐私与脱敏

- 不展示真实微信昵称、头像、联系人、二维码和登录 Token。
- 不展示历史私人会话、个人日程、备忘、地理位置、服务器密钥或浏览器 Cookie。
- 演示文本只使用虚构日程和公开问题。
- 截图完成后逐张人工检查，发现任何个人信息即废弃重拍。

## 示例内容

README 中使用短对话块展示能力，示例包括：

- “给我一份今日晨报” → 天气、日程、待办和编程进度。
- “记住周五提交周报” → 跨进程持久记忆。
- “查询最近一周娱乐新闻” → 配置 Tavily 后返回截至时间和来源。
- “查询电影各平台评分” → 分平台列出量表，不生成综合分。
- “BLG 最近一场比赛比分” → PandaScore 优先、Tavily 回退。
- “上海近期演唱会门票哪里买” → 正规渠道、公开价性质和结算提醒。

示例不写死会快速过期的具体票价、比分或评分数值。

## 验证标准

- README 中的全部图片能通过相对路径在 GitHub 渲染。
- 图片尺寸适合 GitHub 页面，不模糊、不包含敏感信息，单图体积保持合理。
- README 中的内部锚点、外部链接、命令和环境变量与仓库现状一致。
- Mermaid 语法可解析，Markdown 无未闭合代码块或表格。
- 运行全量测试，确保文档提交没有意外改动程序文件。
- `git diff --check` 无输出，提交中不存在 API Key、Token、Cookie 或真实个人数据。

## 发布方式

在 `main` 上完成文档与图片，验证后提交并推送 `origin/main`。提交信息使用文档类前缀，生产服务无需重启，因为本次只更新仓库展示内容。
