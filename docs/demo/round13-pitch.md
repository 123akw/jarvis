# 第十三轮比赛演示剧本：3 分钟拼出你自己的 AI 智能体

2026-10-02 · 对应 `docs/proposals/2026-10-round13-platform.md` 第 3 节用户旅程，按用户修正后的形态：**插件市场挑插件 → 生成专属账号和口令 → 用现有登录页登录 → 进去就是按所选插件形成的专属智能体**；「输入 → 工具 → 输出」积木流程和结果网页二维码保留。界面用语统一叫「智能体」。演示资料是**虚构**的 [`sample-project.md`](sample-project.md)（「邻里鲜」社区团购小程序），**不用会议纪要原文**——原文含真实手机号与邮箱，不得上屏、不得入库。

## 0 一句话主线

> 县城里一个不会写代码的创业小队，3 分钟拿到一个**属于自己的 AI 智能体**：挑几个插件就开好账号，登录进去就是它；资料一丢，待办自动出来，最后变成一张谁都能扫的二维码。

- **人物**：林晓，青石县「邻里鲜」社区团购项目负责人，6 人小队，资料散在微信群和 U 盘里（全部虚构）。
- **三个高光**：一句话 → 推荐插件（第 ③ 屏）· 专属账号口令 → 登录即是自己的智能体（第 ⑤⑥ 屏）· 积木逐个亮起 → 结果二维码（第 ⑧ 屏）。
- **设备**：笔记本（主演示，投大屏，**以游客身份开场**）+ iPhone（投屏，扫码）+ 一台备用手机（开热点）。
- **不依赖飞书**：新开的账号没绑飞书，飞书积木对它不可用。演示流程用「存进待办 + 生成网页与二维码」收尾，飞书只口头带一句。

### 收尾话术（25 秒，可背）

「下沉市场 6.5 亿月活，近一半已经在用 AI，却没有一个工具是为他们拼的。我们卖**插件**：基础插件永久免费；会议纪要、飞书文档、微信助手这些专业插件 9.9 元一个月，全包 19.9 元，不玩自动续费的小把戏。今天这套：**22 个插件、8 个职业套餐、不到 90 秒拿到自己的智能体**。下一步做模板广场——县城奶茶店老板拼好的智能体，下一个县城的同行一键就能用。」

> 市场数据出处：QuestMobile 2026 年下沉市场报告，月活 6.53 亿、AIGC 活跃占比 47.3%（口播「近一半」，PPT 上写原数）。产品数字以**彩排实测**为准（插件数取 `/api/market/catalog`，耗时取彩排计时中位数），不要现场报没测过的数。定价与依据见 `docs/proposals/2026-10-round13-research.md` 第 4 节。

## 2 演示前检查（T-1 天 / T-30 分钟）

| 何时 | 检查项 |
| --- | --- |
| T-1 天 | 演示服务器开放注册：比赛时段设 `JARVIS_MARKET_SIGNUP=open`，或设 `invite` 并把邀请码放剪贴板；向后端确认注册与推荐的**按 IP 限流阈值**，够彩排 + 正式各几次 |
| T-1 天 | **彩排至少 3 遍**（每遍都会开一个新账号）；记下每屏实际耗时；用附录 B 的 8 句描述各测一次推荐；留一个彩排账号的账号口令当备用 |
| T-1 天 | 录一段完整 3 分钟备份录屏 + 三段高光片段（③ 推荐、⑤⑥ 开号登录、⑧ 积木亮起），存在笔记本本地和手机相册各一份 |
| T-1 天 | 结果页二维码分别用 iPhone 相机和**微信扫一扫**各扫一次，确认微信里能直接打开、不被拦成「非官方网页」 |
| T-30 分钟 | 手机热点开好（主网络），场馆 Wi-Fi 作备用；浏览器**退出登录**、只留演示标签页，关通知、开勿扰 |
| T-30 分钟 | 用备用账号预先跑一次「项目资料归档」，保留结果页链接，作为模型慢时的兜底 |
| T-30 分钟 | 大屏二维码实测：在评委座位距离用手机扫一次；二维码边长 ≥ 大屏高度的 1/3，周围留白 |
| T-30 分钟 | 剪贴板里放好示范描述；`sample-project.md` 复制到桌面并改名「邻里鲜项目资料.md」 |

## 3 现场风险与兜底

| 风险 | 征兆 | 兜底（按顺序试，每步不超过 10 秒） |
| --- | --- | --- |
| 网络断 / 慢 | 首屏转圈 > 3 秒 | ① 切手机热点；② 已预加载的标签页照讲，讲解词不变；③ 播放对应高光片段录屏，口头说「为节省时间看录好的这段」 |
| 模型慢（推荐） | 「帮我推荐」 > 5 秒没结果 | 改点职业卡「项目负责人」——走关键词规则（`source: rules`），秒出；讲解词改成「也可以直接选职业」 |
| 注册被拒 / 限流 | 生成时报「暂未开放注册」或请求太频繁 | ① 检查邀请码；② 切热点换出口 IP 再点一次；③ 用备用账号口令登录，讲「开号就是这样一组账号口令」，从第 ⑥ 屏接着讲 |
| 登录失败 | 口令粘贴错 / 结果页被关 | 口令只显示一次——**登录成功前不要关结果页**；回结果页再点「复制」；仍不行就用备用账号 |
| 模型慢（试运行） | 某个积木亮着 > 10 秒不动 | 边等边讲「每一步都给中间结果，不是黑盒」；15 秒仍不动就打开预跑的结果页链接 + 二维码，继续第 ⑨ 屏 |
| 积木报错 | 出现红色「人话原因」 | 顺势讲「出错会用人话告诉你哪一步、为什么」；删掉出错积木再跑一次（体现可拼可拆），或直接用预跑结果 |
| 飞书相关提问 | 评委问「能不能推到飞书」 | 讲「绑定飞书后加一块『汇总到飞书文档』；没有文档权限会自动降级为发消息」，不现场演示 |
| 扫码失败 | 评委扫不出 / 打不开 | ① 放大二维码、调亮屏幕；② 口播短链接；③ 用投屏 iPhone 自己扫给大家看；④ 微信提示「非官方网页」时，讲「点右上角用浏览器打开」，并提前在 Safari 里开好同一页 |
| 超时 | 2:35 还没到收尾 | 跳过第 ⑨ 屏的对话提问，直接收尾；收尾话术不删 |
