# 抽签分组 🎲

随机分组、抽签、排值日表。每次结果都带一个「抽签码」：同一份名单 + 同一个抽签码一定得到同样的结果，可以当众复核，适合班级、门店、团队。纯 Python 标准库，不联网。

工具：

- `lottery_groups(names, group_count=0, group_size=0, seed="")`：随机分组，各组人数最多差 1。
- `lottery_draw(names, count=1, seed="")`：不重复抽人，按抽中顺序列出。
- `lottery_rota(names, start_date, days=5, per_day=1, skip_weekends=False, seed="")`：打乱顺序后按天轮流排值日 / 排班，可跳过周末。

名单用逗号、顿号、分号或换行隔开（都没有时按空格分）；重复的名字自动去掉并提示。上限 200 人、50 组、62 天。

示例：「把张三、李四、王五、赵六分成两组」→

```
共 4 人，分成 2 组：
第 1 组（2 人）：……
第 2 组（2 人）：……
抽签码：3fa9c1（同一名单、同一抽签码会得到同样的结果，可以当众复核）
```

测试：`python -m pytest -q`。许可证：随贾维斯仓库 README 的「声明」（学习、研究与个人非商业用途）。
