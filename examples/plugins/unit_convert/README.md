# 单位换算 📏

斤两公斤、亩和平方米、尺寸英寸、摄氏华氏，一问就换算好。纯 Python 标准库，不联网。

| 类别 | 支持的单位（节选） |
| --- | --- |
| 长度 | 千米 / 米 / 厘米 / 毫米、里 / 丈 / 尺 / 寸、英里 / 码 / 英尺 / 英寸、海里 |
| 重量 | 吨 / 千克 / 克、担 / 斤 / 两 / 钱、磅 / 盎司、克拉 |
| 面积 | 平方千米 / 公顷 / 亩 / 分（地）/ 平方米、英亩 / 平方英尺 |
| 体积 | 立方米（方）/ 升 / 毫升、加仑、斗 / 石 |
| 温度 | 摄氏度 / 华氏度 / 开尔文 |

工具：

- `unit_convert(value, from_unit, to_unit, category="")`：换算并给出「1 X = ? Y」的换算关系；「分」这类多义单位按目标单位判断，判断不了会请用户说明类别。
- `unit_convert_units(category="")`：列出支持的单位。

示例：「3 斤半是多少公斤」→ `3.5 斤 = 1.75 千克（1 斤 = 0.5 千克）`。

测试：`python -m pytest -q`。许可证：随贾维斯仓库 README 的「声明」（学习、研究与个人非商业用途）。
