# 朋友圈文案教练 📣

一个 `kind: skill` 的纯提示词技能：没有代码、不调用工具，只是告诉贾维斯「遇到写朋友圈文案时按什么规矩做」。正文在 `SKILL.md`（第一行 `# 名称`，正文不超过 2000 字）。

装上以后，用户说「帮我写条朋友圈，今天新到了阳山水蜜桃」，贾维斯会：

1. 缺关键信息时最多追问两个（卖什么、给谁看、价格时间地址）；
2. 一次给三版：实在型、故事型、互动型，每版 60–120 字，附「适合什么时候发」和配图建议；
3. 不编造优惠和销量，不用「最好」「第一」「全网最低」这类广告极限词。

想写自己的技能：照这个目录复制一份，改 `plugin.json` 的 `id` / `name` / `summary` / `examples` 和 `SKILL.md` 正文即可。可以搭配「文字体检」插件，让贾维斯写完再自查一遍极限词。

许可证：随贾维斯仓库 README 的「声明」（学习、研究与个人非商业用途）。
