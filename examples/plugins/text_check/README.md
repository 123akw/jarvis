# 文字体检 🩺

数字数、算阅读时长、找重复词，发文案前查一遍广告极限词。纯 Python 标准库，不联网。

工具：

- `text_check(text, sensitive_words="")`：完整体检——字数（汉字 / 英文单词 / 数字 / 标点）、段落与句子、平均句长与过长句、默读和朗读时长、高频重复词、疑似打错的叠字（「的的」「，，」）、广告极限词与自定义敏感词。
- `text_check_ad_words(text, sensitive_words="")`：只查广告极限词（最好、第一、顶级、全网最低、100% 等约 50 个常见说法）和自定义敏感词，并给出改法。

说明：

- 一次最多检查 2 万字；重复词用汉字片段统计近似，不做分词。
- 极限词清单参考《广告法》第九条等常见口径，只是提示，不构成法律意见；各地市场监管尺度以当地为准。

测试：`python -m pytest -q`。许可证：随贾维斯仓库 README 的「声明」（学习、研究与个人非商业用途）。
